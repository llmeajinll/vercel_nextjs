# 기본 규격

사용자 제공 「포트폴리오 디자인 시스템 — Foundations」의 기준이다. 적용·우선순위는 [규칙 안내](README.md)를 따른다.

## 시각적 방향

- 흰 바탕, 무채색 잉크, 하나의 파란 강조색을 사용한다.
- 기본 서체는 Pretendard 하나로 통일하고, 코드에만 monospace를 사용한다.
- 알약형 칩·배지·링크 버튼과 둥근 카드의 형태를 사용한다.
- 장식용 그림자, 그라데이션, 두 번째 강조색을 추가하지 않는다.
- 실제 서비스 캡처와 데모가 담고 있는 서비스 고유 색상은 포트폴리오 UI 토큰으로 혼동하지 않는다.

## 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `ink` | `#1D1D1F` | 제목·기본 본문, 진한 버튼 |
| `ink-2` | `#424245` | 보조 본문, 하위 목록, 노트 글자 |
| `ink-3` | `#6E6E73` | 행 라벨, 메타, 표 머리글 |
| `ink-4` | `#86868B` | 목록 기호와 장식용 표시. 읽어야 하는 본문·라벨·캡션에 사용 금지 |
| `accent` | `#0071E3` | 번호, 부제, 링크, 활성 상태 |
| `line` | `#D2D2D7` | 행 구분선, 칩·배지 테두리 |
| `fill` | `#E8E8ED` | 인라인 코드, 비활성 버튼 배경 |
| `surface` | `#F5F5F7` | 카드, 노트, 푸터 배경 |
| `paper` | `#FFFFFF` | 페이지 배경, 칩 안쪽 |
| `highlight` | `accent`의 14% 불투명도 | 본문 속 핵심 구절의 밑줄형 강조. 굵게 표시와 함께 사용 |

첨부 자료에 기재된 흰 배경 대비는 `ink-3` 약 5.1:1, `ink-4` 약 3.6:1, `accent` 약 4.6:1이다. `ink-4`를 읽기용 글자에 쓰지 않는다. 다른 배경과 조합하면 해당 조합의 대비를 별도로 확인한다.

## 타이포그래피

기본은 `Pretendard Variable`, 코드는 `ui-monospace`다. 아래 크기는 첨부 자료의 데스크톱 기준이며, 반응형은 공통 컴포넌트에서 관리한다.

| 역할 | 크기 | 굵기 | 자간·행간·색상·읽기 폭 |
| --- | --- | --- | --- |
| `display` 상세 페이지 제목 | 96px | 600 | 자간 −0.035em |
| `section` h2 섹션 제목 | 48px | 600 | 자간 −0.025em |
| `next-title` 다음 프로젝트 | 44px | 600 | 자간 −0.03em |
| `case-number` 사례 번호 | 28px | 500 | `accent` |
| `case-title` h3 사례 제목 | 22px | 600 | 자간 −0.02em |
| `subtitle` 제목 아래 한 줄 | 20px | 600 | 항상 `accent` |
| `intro` 소개 문단 | 19px | 400 | 행간 1.7, 읽기 폭 640px |
| `body-l` 섹션 설명 | 17px | 400 | 행간 1.7, `ink-2` |
| `body` 기본 본문 | 16px | 400 | 행간 1.7, `ink` |
| `body-s` 하위 목록·표 본문·보조 설명 | 15px | 400 | 행간 1.6, `ink-2` |
| `row-label` 왼쪽 열 라벨 | 14px | 600 | 자간 +0.01em, `ink-3` |
| `sub-label` 사례 안 소제목·정보 칸 라벨 | 12px | 600 | 사례 안에서는 `ink`, 정보 칸에서는 `ink-3` |
| `meta` 프로젝트 종류 등 | 13px | 400 | `ink-3` |
| `caption` 설명용 캡션 | 12px | 400 | `ink-3` |
| `code` 인라인 코드 | 본문 크기의 0.86em | 문맥에 따름 | monospace, `fill` 배경, 반경 6px, 안쪽 여백 1px 6px |

- 제목·부제·행 라벨·사례 안 소제목·캡션을 서로 다른 역할로 다룬다. 동일한 역할에 13px·14px 등 임의의 변형을 만들지 않는다.
- 화면별 숫자 지정 대신 `Heading`, `Text`, `Label`, `ProjectSubtitle` 등의 역할과 옵션으로 사용한다. 기존 옵션이 기준과 다르면 공통 구현을 먼저 확인한다.
- 큰 제목을 모바일에도 데스크톱 크기로 강제하지 않는다. 기존 공통 컴포넌트의 반응형 방식을 확인하고, 수치가 정해지지 않은 경우 임의로 새 크기를 만들지 않는다.
- 사용자가 지정한 문장 단위 줄바꿈은 데이터와 렌더러에 명시적으로 반영한다. 글자 크기나 컨테이너 폭으로 우연히 맞추지 않는다.

## 레이아웃과 간격

| 항목 | 기준 |
| --- | --- |
| 콘텐츠 최대 폭 | 1160px |
| 왼쪽 라벨 영역 / 오른쪽 본문 영역 | 240px / 나머지 |
| 일반 본문 읽기 폭 | 최대 760px |
| 소개 문단 읽기 폭 | 640px |
| h2 섹션 위 여백 | 72px |
| 정보 행 위·아래 여백 | 각각 40px |
| 행 구분선 | 1px `line` |
| 목록 항목 사이 간격 | 12px |
| 칩 사이 간격 | 8px |
| 한글 줄바꿈 | `word-break: keep-all` |
| 제목 줄바꿈 | `text-wrap: balance` |

- 라벨 영역 240px는 본문 시작점까지의 공간이다. 첨부 Components의 라벨 행은 라벨 240px 다음에 본문이 이어지며, 별도의 간격을 더해 본문 시작점을 밀지 않는다. 기존 `라벨 200px + 간격 40px` 구현도 이 시작점과 맞는지 실제 좌표로 확인한다.
- 좁은 화면에서는 라벨을 본문 위로 배치한다. 데스크톱 열 너비 때문에 모바일 본문이 좁아지거나 가로로 넘치게 하지 않는다.
- 목차가 본문 너비를 차지하지 않도록 한다. 본문 폭과 읽기 폭은 서로 다른 기준이다.

## 모서리와 경계

| 반경 | 용도 |
| --- | --- |
| 6px | 인라인 코드 |
| 14px | 노트, 목차 패널 |
| 18px | 일반 카드, 화면 이미지 |
| 28px | 메인 프로젝트 카드 |
| 980px | 칩, 배지, 링크 버튼 |

- 면은 `surface`, 경계는 1px `line`으로 구분한다. 장식용 그림자를 사용하지 않는다.
- 표의 첫 가로선만 1px `ink`로 시작한다. 자세한 표 구성은 [컴포넌트 규칙](design-components.md)을 따른다.
- 자료에 없는 모서리 크기·색상·간격을 기존 파일에서 발견해도 새 기준으로 복제하지 않는다.
